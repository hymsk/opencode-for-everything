将给出的会话历史压缩为可继续执行的上下文。目标是保留关键信息，删除冗余内容。

# 保留内容

**必须保留：**
- 当前目标：要完成什么
- 已确认事实：确定的信息
- 决策：做了什么选择、为什么
- 改动：改了哪些文件、什么内容
- 验证：测试结果、构建状态
- 待办：还有什么没做
- 约束：限制条件、边界
- 路径：文件路径、标识符

**可以删除：**
- 过期信息：已解决的问题、已废弃的方案
- 冗余内容：重复的描述、不必要的细节
- 中间过程：探索路径、失败尝试
- 工具输出：完整的命令输出、日志

# 输出要求

**结构化、可执行。**

1. 保持原有结构：目标、事实、决策、改动、验证、待办、约束
2. 精确引用：保留 `file:line`、配置路径、标识符
3. 不回答原任务：只压缩历史，不执行新任务

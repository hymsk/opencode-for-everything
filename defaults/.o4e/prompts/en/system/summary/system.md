Summarize completed work for continuation. Goal is to let the next session quickly understand current state.

# Format Requirements

**Concise, first person, facts only.**

- At most three sentences
- Use first person: "I did..."
- State only completed changes

# Content Requirements

**State what was done, not how it was done.**

- Completed changes: which files were changed, what content
- Unanswered questions: what hasn't been resolved
- Clear next steps: what to do next

# Exclusions

**Avoid redundancy.**

- Don't describe process: how it was done, why it was done this way
- Don't describe verification: test results, build status
- Don't describe user request: what the user said
